# Real Estate Management System

Welcome to the **Real Estate Management System**, a Laravel-based application designed to simplify and streamline real estate operations. This project features three main user roles: **Admin**, **Agent**, and **User**, each with tailored functionalities for managing listings, inquiries, and transactions.

## Features

### Admin Panel
- Manage property listings.
- Approve or reject agent registrations.
- View and manage user inquiries.
- Generate reports and monitor system activity.

### Agent Dashboard
- Add and manage property listings.
- Respond to user inquiries.
- Track property performance and client engagement.

### User Functionality
- Browse and search properties.
- Contact agents for property inquiries.
- Create and manage a personal wishlist.

## Technology Stack

- **Framework**: Laravel
- **Database**: MySQL
- **Frontend**: Blade Templates, Bootstrap
- **Authentication**: Laravel Breeze/Jetstream
- **Real-time Features**: Laravel Echo & Pusher
